Featured project

From scattered records to one clear view.

The standout contribution was a more structured way to manage worker-induction information — linking how people actually enter a site with simple, reliable data tools the team can use every day.

Worker induction tracking system

One process. One record. One status view.

Designed to make intake, tracking, and reporting easier. The system pairs a central spreadsheet with automation and a visual dashboard so induction status is easy to check and discuss.

  1. Unified intake — standardised the information captured during induction.
  2. Central Google Sheet — kept records in one accessible source of truth.
  3. Apps Script automation — reduced manual handling and kept records updated.
  4. HTML + Power BI dashboard — made induction status easier to monitor and share.
